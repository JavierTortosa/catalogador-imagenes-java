DOCUMENTO DE DISEÑO FUNCIONAL (v1.0)
=========================================================

OBJETIVO
========

El objetivo NO es desarrollar un clon de Photoshop.

El objetivo es crear un editor gráfico sencillo, rápido y cómodo que permita
componer imágenes (principalmente PNG con transparencia) para generar una
previsualización de modelos STL contenidos en archivos comprimidos.

Debe permitir montar imágenes con rapidez, utilizando únicamente las
herramientas realmente necesarias.

La filosofía del proyecto es:

    "Pocas herramientas, bien implementadas."

La interfaz debe ser clara y consistente.
Cada herramienta únicamente mostrará las opciones que realmente necesita.

=========================================================
HERRAMIENTA TRANSFORMAR
=========================================================



OBJETIVO

Manipular objetos mediante un único gizmo.

No existirá una herramienta "Mover".

Transformar realizará:

- mover
- escalar
- rotar

sobre:

- una capa
- una selección

según decida el usuario.


---------------------------------------------------------
Selector de transformación
---------------------------------------------------------

Existirá un selector con tres opciones.

○ Página
○ Capa
○ Selección

Pagina

El gizmo actuará sobre la pagina entera sin hacer distincion de capas

Selección

El gizmo actuará sobre el marco de selección.

Capa

El gizmo actuará sobre la capa activa.

De esta forma el usuario decide qué desea transformar
evitando modificaciones accidentales.


---------------------------------------------------------
Opciones superiores
---------------------------------------------------------

X

Posición horizontal.

Y

Posición vertical.

W

Anchura.

H

Altura.

[groupbutton]
□ Mover [toggle]
□ Rotar [toggle]
□ Escalar [toggle]
[endgroupbutton]

□ Mantener proporción / Transformacion Libre (checkbox)

Al escalar mantiene la relación ancho/alto o nos permite cambiar las proporciones a voluntad.

□ Ajustar a cuadrícula (opcional) (dpad nuevo)

Permite alinear los objetos fácilmente.


---------------------------------------------------------
Implementación
---------------------------------------------------------

Se implementará un único TransformGizmo.

Este objeto será independiente de la herramienta.

Será reutilizable por:

- capas
- selecciones
- texto
- formas
- cualquier objeto futuro


El gizmo será responsable de:

- dibujar el marco
- dibujar los tiradores
- detectar el tirador pulsado
- mover
- escalar
- rotar
- mostrar cursores adecuados


La herramienta Transformar únicamente seleccionará
qué objeto controla el gizmo.

=========================================================
VARITA MÁGICA
=========================================================

OBJETIVO

Seleccionar zonas similares automáticamente.


---------------------------------------------------------
Opciones superiores
---------------------------------------------------------

Tolerancia

Determina cuánto puede variar un color respecto al
color pulsado.

Valor pequeño

Selecciona colores muy parecidos.

Valor grande

Selecciona colores más diferentes.


□ Contiguo

Activado

Solo selecciona píxeles conectados.

Desactivado

Selecciona todos los píxeles similares del documento.


No existirán:

- Añadir selección
- Muestrear todas las capas
- AntiAlias


=========================================================
RECORTAR
=========================================================

OBJETIVO

Trabajar únicamente sobre una selección existente.


Opciones

○ Eliminar contenido

Borra la selección.

○ Nueva capa

El contenido seleccionado pasa a una nueva capa.

□ Mantener original

Si está activado se conserva la capa original.

=========================================================
ZOOM
=========================================================

OBJETIVO

Modificar el nivel de zoom del editor.


El zoom se realizará mediante la rueda del ratón.


Existirán dos modos.


Modo normal

El zoom se realiza respecto al centro de la pantalla.


Modo al cursor

El zoom mantiene bajo el cursor el punto sobre el que
se está trabajando.

Este será el modo recomendado.


Opciones

☑ Zoom al cursor

☐ Zoom al centro

=========================================================
ARQUITECTURA DE HERRAMIENTAS
=========================================================

Todas las herramientas heredarán de una clase base.


Ejemplo


abstract class Tool {

    mousePressed(...);

    mouseDragged(...);

    mouseReleased(...);

    paintOverlay(...);

    getOptionsPanel();

}


Responsabilidades

mousePressed

Inicio de la acción.

mouseDragged

Actualización mientras se mueve el ratón.

mouseReleased

Finalización.

paintOverlay

Dibujar elementos temporales.

Ejemplos

- marco de selección
- gizmo
- vista previa

getOptionsPanel

Devuelve el panel que aparecerá en la parte específica
de la barra superior.

=========================================================
FILOSOFÍA FINAL DEL PROYECTO
=========================================================

Este editor no pretende competir con Photoshop.

Pretende ser una herramienta especializada para crear
imágenes de previsualización de modelos 3D de forma
rápida, sencilla y cómoda.

Todas las decisiones de diseño deben responder siempre
a una única pregunta:

"¿Hace más rápido generar una buena previsualización?"

Si la respuesta es sí, la función merece implementarse.

Si la respuesta es no, probablemente no forme parte de
la filosofía del proyecto.

14. PANEL DE CAPAS (lado derecho) — TARJETAS

En lugar de JList/JTable, se usan tarjetas visuales apiladas verticalmente
en un JPanel dentro de JScrollPane. Cada tarjeta representa una capa.

Componente	Descripción
LayerCardPanel	JPanel con BoxLayout.Y_AXIS dentro de un JScrollPane. Se reconstruye desde LayerModel.getLayers()
LayerCard	JPanel individual con: JLabel miniatura (48x48 escalado), JTextField nombre (editable, sin borde, fondo transparente), JToggleButton ojo (visible/oculto), fondo coloreado si seleccionada

Comportamiento:
- Click en tarjeta → layerModel.setActiveLayer(idx) + repintar selección en el listado
- Reconstrucción completa al añadir/eliminar/reordenar capas (layerModel dispara evento)
- El ojo toggle modifica ImageLayer.visible + repaint canvas
- El JTextField modifica ImageLayer.name

Botones inferiores (JToolBar o JPanel horizontal):
  [+ Nueva] [⎘ Duplicar] [🗑 Eliminar] [Opacidad slider]
