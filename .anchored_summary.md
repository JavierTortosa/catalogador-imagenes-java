## Constraints & Preferences
- Servicios 100% headless: sin imports de `javax.swing.*`, `vista.*`, ni `registry`.
- `ProjectUIManager` concentra toda la UI pura (colores, bordes, píxeles, `JPopupMenu`).
- Datos planos o `Tema` como parámetros entre controller y UIManager; el UIManager no conoce el modelo ni `GeneralController`.
- 2 líneas en blanco entre el `}` de cierre y el `//` del comentario descriptivo del siguiente método.
- Inyección de dependencias por constructor en servicios; setters en `ProjectController`.

## Key Decisions
- Servicios no tienen `crearWorker()` — el controller crea `ExportWorker` directamente.
- `PdfWorkflowService.generarPDF()` no normaliza extensión `.pdf` — el controller lo hace antes del overwrite check.
- `ProjectFileManagementService`, `ProjectIntegrityService`, `ProjectSyncService` usan constructor injection.
- `ProjectSyncService.getSourceData()` devuelve `List<String>` (no `List<Path>`); el controller crea `DefaultListModel` (Swing).
- `ProjectUIManager` recibe `ComponentRegistry` en constructor; `Tema` y datos planos como parámetros de método. No recibe `model` ni `GeneralController`.
- Script Python usado para añadir comentarios en masa (más robusto que PowerShell para parsing de código Java).
