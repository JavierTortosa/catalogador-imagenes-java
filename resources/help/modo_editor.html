Modo Editor

El Modo Editor es un modo de trabajo dedicado (como Modo Proyecto, Modo Datos o Modo Render) que abre el Editor Avanzado a pantalla completa para editar imágenes con capas y guardar el trabajo en documentos propios con extensión .edoc.

Se activa desde el botón Modo Editor de la barra de modos (). Al entrar se ocultan los paneles laterales del Modo Render (previsión 3D y archivos) para que el lienzo ocupe toda la zona de trabajo, y al salir se restauran. Es el mismo editor que se usa dentro del Modo Render, pero con su documento propio e independiente: lo que edites aquí no afecta a la composición del editor del Modo Render, y viceversa.

Documento del Editor (.edoc)

Cada edición se organiza como un documento con las capas y el lienzo (estilo Photoshop). El documento se guarda en un archivo .edoc (JSON) junto con una carpeta <archivo>_capas/ donde se exportan los PNG de las capas sin origen (pintadas, degradados, fusiones, formas...).

  • Un documento sin guardar se considera un temporal (editor_temporal.edoc).
  • Al modificar el lienzo (pintar, transformar, mover, añadir capas...) el documento se marca como con cambios pendientes y el título de la ventana muestra un asterisco (*) delante del nombre del documento.
  • Al guardar, desaparece el * y el nombre pasa a ser el del archivo guardado.

Barra de Documento

En el Modo Editor se muestra la barra de documento con las operaciones básicas del archivo:

Nuevo documento: Reinicia el lienzo por defecto, sin capas.
Abrir documento: Carga un documento .edoc existente.
Guardar documento: Guarda en el archivo activo, o en el temporal si aún no tiene nombre. Si el archivo ya existe se pregunta antes de sobrescribirlo.
Guardar como: Elige un archivo y nombre para el documento.
Pegar imagen (Ctrl+V): Inserta la imagen del portapapeles como una nueva capa centrada en el lienzo.

Documentos Independientes (Render y Editor)

El editor avanzado mantiene dos documentos separados en memoria:

  • Documento RENDER: la composición que se edita con el editor dentro del Modo Render (botón Editor Avanzado de la previsualización). Es un lienzo de trabajo en memoria, sin archivo asociado.
  • Documento EDITOR: el documento del Modo Editor, con su propia gestión de guardado en .edoc (nombre, cambios pendientes, recuperación).

Al cambiar entre el Modo Render y el Modo Editor, cada uno conserva intacto su documento aunque uses el mismo editor. Para llevar contenido de uno a otro se usa el portapapeles: Copiar imagen en un contexto y Pegar (Ctrl+V) en el otro.

Cambiar de Modo

El editor mantiene el trabajo en memoria mientras cambias de modo con la barra de modos (misma semántica que el Modo Proyecto). Al salir del Modo Editor, si el documento tiene cambios sin guardar y no tiene nombre, se guarda automáticamente en el temporal editor_temporal.edoc para no perderlo.

Cerrar la Aplicación

Si cierras la aplicación con el documento marcado con *, se muestra el aviso Guardar / No Guardar / Cancelar:

  • Guardar: Guarda el documento (pregunta la ruta si no tiene nombre).
  • No Guardar: Se guarda una sesión de recuperación automática del trabajo.
  • Cancelar: No se cierra la aplicación y se conserva la edición.

Recuperación al Entrar

Al volver a abrir la aplicación y entrar en el Modo Editor, si se dejó un documento sin guardar se pregunta: "Dejaste un documento sin guardar. ¿Cargarlo o descartar?".

  • Cargar: Recupera el trabajo tal y como estaba, conservando el nombre original del documento (con *, para que no sobrescriba la sesión de recuperación).
  • Descartar: Empieza con un lienzo limpio.
  • Cancelar: No entra en el Modo Editor.

Una vez recuperado con éxito, la sesión de recuperación se elimina automáticamente.

Copiar y Pegar Imágenes

El sistema usa el portapapeles del sistema (imágenes), por lo que también puedes pegar capturas desde otras aplicaciones (Paint, WhatsApp, navegador...) y copiar para usarlas fuera del visor.

  • Copiar imagen (clic derecho sobre una imagen → Copiar imagen): Copia la imagen actual del contexto:
    • En Visualizador / Proyecto / Cliente: la imagen seleccionada.
    • En Render: lo que se ve en pantalla (si el editor avanzado está activo, aplana las capas visibles; si está la vista 2D, aplana el collage).
    • En Editor: la composición visible aplanada.
  • Pegar en el editor (Ctrl+V o botón Pegar de la barra de documento): crea una capa "Imagen pegada" centrada en el lienzo, que queda activa y lista para mover o redimensionar.

Panel de Disposición y Auto Layout

En la columna derecha del editor, la sección Disposición agrupa las operaciones de composición de capas: Alinear, Distribuir, Espacio y el sistema Auto Layout (13 herramientas que componen automáticamente las capas seleccionadas: Grid Uniforme, Grid Conservando Tamaño, Compactar, Filas/Columnas, Layout Hero, Espiral, Mosaico, Ajustar al Canvas, Centrar e Igualar). La pestaña Opciones permite configurar la referencia de alineación y los parámetros de Auto Layout (espaciado, márgenes, escala hero, variación de mosaico y algoritmo de empaquetado).

Para el detalle de las herramientas, el panel de capas, el gizmo de transformación, la edición de texto y el sistema Auto Layout, consulta la guía del Editor Avanzado.
