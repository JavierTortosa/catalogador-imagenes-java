El Panel de Navegación Izquierdo

Este panel es tu centro de control para encontrar y filtrar las imágenes que quieres visualizar. Está organizado en tres pestañas con funcionalidades muy potentes.

Pestaña Lista

Muestra una lista con los nombres de archivo de las imágenes en la carpeta actual. La barra de herramientas superior te permite navegar y filtrar esta lista.

Barra de Herramientas

Navegar a Carpeta Raíz: Vuelve a la carpeta principal que abriste inicialmente.
Subir un Nivel: Navega a la carpeta contenedora de la actual, guardando el historial para poder regresar.
Entrar en Subcarpeta: Si tienes una subcarpeta seleccionada en la lista, este botón te permite navegar dentro de ella, guardando el historial.
Ciclo de Orden: Cambia el orden de los archivos (por defecto, A-Z, Z-A).
Filtro "Tornado" (Filtro en Vivo): Cuando está activo, el campo de texto filtra la lista de archivos en tiempo real mientras escribes. Si está desactivado, el campo de texto sirve para buscar la siguiente coincidencia al pulsar Enter.
Hacer Filtro Persistente (+): Toma el texto del filtro y lo añade como filtro permanente en la pestaña "Filtros". Si hay varios términos separados por coma, se crea una regla por cada uno.

Campo de Búsqueda / Filtro Rápido

El campo de texto con el placeholder "Texto a buscar..." te permite localizar imágenes de forma rápida. Su comportamiento cambia según el estado del botón "Tornado":

  • Con Tornado APAGADO — Pulsa Enter para buscar la siguiente imagen que contenga el texto escrito, a partir de la selección actual. Cada vez que pulses Enter saltará a la siguiente coincidencia.
  • Con Tornado ENCENDIDO — La lista se filtra en vivo mientras escribes, mostrando solo las imágenes cuyo nombre contenga el texto. El filtro se aplica con una pequeña demora (300 ms) para no relentizar la interfaz.
  • Búsqueda múltiple: Usa una coma ( , ) para separar varios términos. Por ejemplo, "desktop, phone" mostrará las imágenes que contengan ambas palabras.
  • Persistir filtro: El botón "+" (Hacer Filtro Persistente) toma el texto del campo y lo añade como una o varias reglas de filtro permanente en la pestaña "Filtros". Si escribiste varios términos separados por coma, se creará una regla por cada uno.

Pestaña Carpetas

Muestra una vista de árbol de tu sistema de archivos. Esta pestaña tiene un sistema de navegación con historial:

  • Doble Clic (o "Abrir aquí" con clic derecho): Carga la carpeta seleccionada como la nueva carpeta raíz. Esto limpia el historial de navegación y establece un nuevo punto de partida. Es como usar "Archivo > Abrir Carpeta".
  • Clic Simple (o "Entrar en esta carpeta" con clic derecho): Entra en la carpeta de forma temporal, guardando tu ubicación anterior en el historial. Puedes volver a la carpeta anterior usando el botón "Subir un Nivel" de la Pestaña Lista.

Pestaña Filtros

Aquí puedes construir filtros complejos y persistentes para mostrar solo las imágenes que te interesan. Puedes combinar múltiples reglas.

/ / Fuente del Filtro: Elige si el texto se buscará en el nombre del archivo, en la ruta de la carpeta o en las etiquetas (tags) de la base de datos.
/ Tipo de Filtro: Añade un filtro positivo [+] (la imagen DEBE contener el texto) o un filtro negativo [-] (la imagen NO DEBE contener el texto).
Eliminar Filtro: Quita la regla de filtro que tengas seleccionada en la lista de filtros activos.
Limpiar Todos: Elimina todas las reglas de filtro activas y vuelve a mostrar la lista completa de archivos.

Navegación Jerárquica de Etiquetas con "."

Cuando añades un filtro de tipo "Etiqueta" o trabajas con el campo de asignación de etiquetas en el Modo Datos, puedes usar el punto (.) para navegar por la jerarquía de etiquetas de forma rápida:

  • "." — Muestra todas las etiquetas raíz (padres).
  • ".texto" — Muestra todas las etiquetas que empiecen por "texto", estén donde estén en la jerarquía.
  • ".padre." — Muestra todos los hijos directos de "padre".
  • ".padre.pre" — Muestra los hijos de "padre" que empiecen por "pre".
  • "texto" (sin punto) — Búsqueda plana: muestra todas las etiquetas que empiecen por "texto".

Teclas: Tab = seleccionar la etiqueta resaltada y cerrar el panel. . = seleccionar la etiqueta y bajar un nivel (abre automáticamente el "." final). ↑ ↓ = navegar por la lista de sugerencias. Enter = confirmar el contenido del campo (no selecciona del panel).

Checkbox "Incluir ruta completa": Al añadir un filtro de etiqueta, activa esta opción para que se cree un filtro por cada ancestro de la ruta. Por ejemplo, ".trofeos.blood bowl" generará dos filtros: "trofeos" y "blood bowl". Si está desactivado, solo se filtra por la etiqueta final ("blood bowl").

Consejo Pro: Puedes añadir filtros de carpeta rápidamente haciendo clic derecho sobre la ruta de la imagen o de la carpeta en las barras de información del visor.
