Paneles del Modo Datos

El Modo Datos utiliza una disposición de paneles diseñada para maximizar la eficiencia de la gestión de activos. Cada panel tiene un propósito específico en el flujo de trabajo.

1. Panel de Cuadrícula de Datos (Grid)

Es el panel principal de visualización en este modo. Muestra una cuadrícula de miniaturas de las imágenes seleccionadas o del proyecto actual.

  • Navegación Visual: Desplázate rápidamente por tus imágenes.
  • Indicadores de Estado: Las miniaturas muestran bordes de colores que indican su estado (por ejemplo, si están listas para exportar o si tienen conflictos).
  • Gestión de Etiquetas: Desde aquí puedes acceder rápidamente a las herramientas de etiquetado.

2. Panel de Exportación

Situado habitualmente en el lateral derecho, este panel es la estación final para tus procesos de salida.

  • Cola de Exportación: Visualiza todas las imágenes y archivos que has seleccionado para la próxima copia.
  • Gestión de Asociaciones: Permite añadir archivos relacionados (como modelos 3D) a cada elemento de la cola.
  • Configuración de Destino: Define dónde se guardará tu trabajo final.

3. Panel de Propiedades y Metadatos

Proporciona un acceso directo a la información detallada del proyecto y de los elementos seleccionados. Permite editar la descripción del proyecto y otros metadatos clave de forma sencilla.
