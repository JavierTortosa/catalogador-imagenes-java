Sistema de Etiquetas (Tags)

El sistema de etiquetas es el núcleo de la inteligencia de la aplicación. Permite transformar una simple lista de archivos en una base de datos categorizada y fácilmente consultable.

¿Cómo funcionan las etiquetas?

Cada imagen en tu proyecto o colección puede tener una o más etiquetas asociadas. Estas etiquetas se guardan de forma persistente y se utilizan para alimentar el motor de filtrado "Tornado", permitiéndote encontrar instantáneamente grupos de imágenes que comparten características comunes.

Asignación de Etiquetas

Existen varias formas de gestionar tus etiquetas:

  • Asignación Masiva: Selecciona múltiples imágenes en el panel de la lista y utiliza la opción "Asignar Etiqueta..." desde el menú contextual para aplicar una etiqueta a todas ellas simultáneamente.
  • Edición Individual: A través del panel de propiedades o mediante acciones rápidas, puedes modificar la etiqueta de una imagen específica.
Consejo Pro: Utiliza etiquetas consistentes y cortas. Esto no solo facilita la lectura, sino que hace que el motor de búsqueda sea aún más rápido y eficiente.

Persistencia y Sincronización

Las etiquetas se guardan automáticamente en tu archivo de proyecto .prj o en la base de datos central, asegurando que tu organización se mantenga intacta cada vez que abras la aplicación.
