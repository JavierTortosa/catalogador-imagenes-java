Modo Datos

El Modo Datos es el entorno avanzado de gestión de la aplicación. A diferencia de la simple navegación, este modo permite realizar operaciones profundas sobre la información asociada a tus imágenes, permitiéndote construir una base de datos rica y estructurada de tus colecciones.

Funcionalidades Principales

En este modo, el usuario pasa de ser un espectador a ser un gestor de activos digitales. Las capacidades principales incluyen:

  • Gestión de Etiquetas (Tags): Asigna metadatos descriptivos a tus imágenes para una búsqueda y filtrado ultra-rápidos.
  • Asociación de Archivos: Vincula archivos adicionales (como modelos 3D, archivos de configuración o comprimidos) a tus imágenes para mantener toda la información relacionada en un solo lugar.
  • Intellisense de Datos: Aprovecha la potencia del autocompletado para agilizar la entrada de datos y evitar errores de escritura.
  • Organización Avanzada: Utiliza paneles especializados para visualizar y manipular grandes volúmenes de datos de forma coherente.
