Intellisense y Autocompletado

Para acelerar tu flujo de trabajo y minimizar errores humanos, el Modo Datos integra un sistema de Intellisense inteligente.

¿Qué es el Intellisense en este sistema?

El Intellisense es una funcionalidad de asistencia que "predice" lo que estás intentando escribir, basándose en el contexto de los datos que ya existen en tu proyecto o colección.

En el Sistema de Etiquetas (Tags)

Cuando estás asignando una etiqueta o buscando una existente, el sistema te ofrecerá sugerencias basadas en las etiquetas que ya has utilizado anteriormente.

  • Sugerencias en tiempo real: A medida que escribes, aparecerá una lista de coincidencias posibles.
  • Prevención de Duplicados: Te ayuda a mantener la consistencia, evitando que crees etiquetas casi idénticas (ej: "Foto" vs "Fotos").

En la Gestión de Archivos

Al realizar búsquedas o añadir archivos asociados, el sistema te asistirá con los nombres de archivos y rutas existentes, permitiéndote completar la información con solo un par de pulsaciones de tecla.

Consejo de Uso: Utiliza las teclas de dirección (flechas) para navegar por las sugerencias y la tecla Enter para aceptar la que desees.
