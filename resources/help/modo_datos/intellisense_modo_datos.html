Intellisense y Autocompletado

Para acelerar tu flujo de trabajo y minimizar errores humanos, el Modo Datos integra un sistema de Intellisense inteligente con navegación por rutas jerárquicas.

Gramática de Búsqueda por Puntos

El campo de etiquetas interpreta el punto (.) como un operador de navegación sobre la jerarquía de etiquetas. Según cómo uses el punto, el comportamiento cambia:

Modo Ejemplo Qué hace
PLAIN (texto plano) foto Busca todas las etiquetas cuyo nombre empiece por "foto", en toda la base de datos.
WILDCARD (punto inicial) .escu Busca cualquier etiqueta (en cualquier nivel) cuya ruta completa contenga "escu".
PATH (navegación + prefijo) armas.escu Busca hijos de "armas" cuyo nombre empiece por "escu". El padre debe escribirse exactamente.
DRILL_DOWN (punto final) .armas. Muestra todos los hijos directos de "armas" (útil para explorar la jerarquía).

Ejemplos prácticos

  • Escribe retrato → te aparecen todas las etiquetas que empiezan por "retrato".
  • Escribe .paisaje → encuentra etiquetas como "playa", "paisaje urbano", etc. en cualquier rama.
  • Escribe lugares.pla → busca todos los hijos de "lugares" que empiecen por "pla".
  • Escribe .lugares. → lista todos los hijos directos de "lugares" para explorar.

Atajos de Teclado

  • ↑ / ↓ — Navegar por la lista de sugerencias.
  • TAB — Aceptar la sugerencia seleccionada e insertar la ruta completa.
  • Punto (.) — Si hay una sugerencia seleccionada, la inserta y añade un punto al final para continuar profundizando (drill-down automático).
  • ENTER — Aceptar y cerrar la lista. Si la ruta escrita no existe, abre un diálogo de confirmación para crear la etiqueta nueva.
  • ESC — Cerrar la lista de sugerencias sin seleccionar.

Flujo de Creación de Etiquetas

Si escribes una ruta que no existe y presionas ENTER (o pierdes el foco del campo), el sistema detecta automáticamente el último segmento como una nueva etiqueta. Se mostrará un diálogo de confirmación preguntando si deseas crearla bajo la etiqueta padre correspondiente. Si aceptas, la etiqueta se persiste en la base de datos y el campo se actualiza con la ruta completa.

Consejo de Uso: Usa el modo DRILL_DOWN (.raiz.) para explorar la jerarquía completa de etiquetas antes de escribir. La tecla Punto sobre una sugerencia te permite profundizar sin soltar la navegación.
