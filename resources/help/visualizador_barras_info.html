Barras de Información y Estado

El visor cuenta con dos barras de información interactivas que proporcionan datos en tiempo real sobre la imagen seleccionada y la carpeta de trabajo actual. Puedes mostrar u ocultar cada una de estas barras desde el menú Vista.

Barra de Información Superior (Info. de Imagen)

Esta barra se centra en la imagen que estás viendo en ese momento. Muestra:

  • Ruta de la Imagen: Muestra la carpeta donde se encuentra físicamente el archivo actual.
  • Nombre Archivo: Muestra el nombre del archivo de imagen.
  • Datos Técnicos:
    • Dim: Dimensiones originales en píxeles.
    • Tam: Tamaño del archivo en disco.
    • Fch: Fecha de última modificación.
    • Idx: Posición de la imagen en la lista actual (ej. 5/100).
    • %Z: Nivel de zoom real aplicado en pantalla.
    • Fmt: Formato del archivo (JPG, PNG, etc.).

Barra de Estado Inferior (Estado y Carpeta Raíz)

Esta barra muestra información sobre la sesión de trabajo y controles globales:

  • Carpeta Raíz: Muestra la ruta de la carpeta que tienes abierta actualmente. Es la ubicación "base" desde la que se cargan todas las imágenes.
  • Indicadores de Estado:
    • Estado del Zoom Manual.
    • Estado de la Lectura de Subcarpetas.
    • Estado de Mantener Proporciones.
  • Controles de Zoom:
    • Z: 100%: Zoom personalizado. Haz clic para abrir un menú de niveles fijos.
    • Selector de Modo de Zoom Automático.
  • Área de Mensajes: Notificaciones del sistema (ej. "[MARCADA]" si pertenece a un proyecto).

Interactividad en las Rutas

Tanto el campo de ruta de la barra superior como el de la barra inferior son interactivos. Al hacer clic derecho sobre ellos, aparecerá un menú especial:

Copiar Ruta: Copia la ruta completa al portapapeles, limpia de prefijos.
Añadir como Filtro (+): Establece un filtro positivo para que solo se muestren imágenes dentro de esa carpeta.
Añadir como Filtro (-): Establece un filtro negativo para ocultar todas las imágenes de esa carpeta.

Comportamiento en Modo Proyecto

Cuando activas el Modo Proyecto, la lógica de las barras de información se adapta para reflejar tu trabajo de selección:

  • Barra Inferior (Sesión): El campo de "Carpeta Raíz" ya no muestra una carpeta del disco, sino la ruta del archivo de proyecto (.prj) actual. Esto te permite saber qué base de datos de selección tienes cargada en cada momento.
  • Barra Superior (Imagen): Sigue mostrando la ubicación física real de la imagen seleccionada. Como un proyecto puede contener imágenes de carpetas muy distintas, esta barra es vital para saber dónde está guardado el archivo original mientras navegas por tu selección.
