Base de Datos

Ruta de la base de datos SQLite y operaciones de mantenimiento.

Configuración

ParámetroDescripción
Ruta base de datos Ubicación de la base de datos SQLite. Vacío = ubicación por defecto en la carpeta de la aplicación.
Reconstruir índices Ejecuta REINDEX + VACUUM para reparar y compactar la base de datos.

Mantenimiento

Cuatro operaciones en pestañas:

OperaciónDescripción
Imágenes Huérfanas Busca imágenes registradas en la base de datos cuyos archivos ya no existen en disco y ofrece eliminarlas.
Etiquetas Sin Uso Busca etiquetas sin ninguna imagen asociada ni hijas y las elimina (las de sistema se omiten).
Ramas Vacías Busca ramas completas de etiquetas sin imágenes asociadas y las elimina (las de sistema se omiten).
Fusionar Etiquetas Transfiere todas las imágenes de una etiqueta origen a una etiqueta destino y elimina la origen.
