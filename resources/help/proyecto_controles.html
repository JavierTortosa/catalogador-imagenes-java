Controles y Acciones del Modo Proyecto

El Modo Proyecto cuenta con barras de herramientas específicas para gestionar tus colecciones de forma eficiente.

Indicador de Cambios Sin Guardar

Cuando realices cambios en tu proyecto (como marcar imágenes, añadir etiquetas o mover archivos a descartes), aparecerá un asterisco (*) al final del nombre del proyecto en la barra de título de la aplicación.

Este símbolo te indica que hay modificaciones que aún no han sido guardadas en el archivo .prj. Al guardar el proyecto (Ctrl+S), el asterisco desaparecerá.

Barra de Herramientas Principal (Superior)

Esta barra contiene los controles de gestión del archivo de proyecto.

Mover a Descartes / Restaurar: (Atajo: Barra Espaciadora). Si una imagen está en "Selección Actual", la mueve a "Descartes". Si está en "Descartes", la restaura a "Selección Actual".
Nuevo Proyecto (Ctrl+N): Cierra el proyecto actual y crea uno nuevo, vacío y temporal.
Abrir Proyecto (Ctrl+O): Abre un diálogo para cargar un archivo de proyecto .prj existente.
Guardar Proyecto (Ctrl+S): Guarda los cambios en el archivo .prj actual. Si es un proyecto temporal, se comportará como "Guardar Como...".
Guardar Proyecto Como (Ctrl+Shift+S): Guarda el proyecto actual en un nuevo archivo .prj.
Panel de Control de Asignaciones: (Atajo: disponible también en el menú Proyecto). Muestra u oculta el panel de exportación y gestión de asignaciones, donde podrás preparar, asignar archivos comprimidos y lanzar la copia final de tu proyecto. Consulta la Guía del Panel de Exportación para más detalles.
Eliminar Proyecto: (Funcionalidad futura) Permitirá eliminar el archivo .prj del disco.

Herramientas del Grid

Cuando estás en la vista de cuadrícula (Grid), una barra de herramientas especial aparece para gestionar las etiquetas.

Etiquetar (Ctrl+T): Abre un diálogo para añadir o editar la etiqueta de la imagen seleccionada.
Borrar Etiqueta (Ctrl+Supr): Elimina la etiqueta de la imagen seleccionada.
Aumentar Tamaño (Ctrl + '+'): Hace las miniaturas del grid más grandes.
Reducir Tamaño (Ctrl + '-'): Hace las miniaturas del grid más pequeñas.
Mostrar Estado: Activa o desactiva un borde de color en las miniaturas (verde/amarillo/rojo) que refleja su estado en la cola de exportación.

Menús Contextuales (Clic Derecho)

Hacer clic derecho en diferentes áreas ofrece acciones rápidas:

Sobre la lista «Selección Actual»

  • Mover a Descartes: Envía el elemento seleccionado a la lista de Descartes.
  • Localizar Archivo: Abre el explorador en la carpeta que contiene el archivo.
  • Añadir Archivos al Proyecto: Abre un diálogo para añadir directamente uno o más archivos a la lista de Selección. Admite imágenes (.jpg, .png, .gif, .bmp) y también archivos sin imagen como modelos 3D (.stl, .obj, .3mf) o comprimidos (.zip, .rar, .7z).
  • Asignar Etiqueta...: Abre un diálogo para añadir o modificar la etiqueta de la imagen seleccionada.

Intellisense en Selección: Al usar las opciones de añadir archivos o etiquetas, el sistema te asistirá sugiriendo nombres de archivos o etiquetas existentes, agilizando la entrada de datos.


Sobre la lista «Descartes»

  • Restaurar a Selección: Devuelve el elemento a la lista de Selección Actual.
  • Localizar Archivo: Abre el explorador en la carpeta que contiene el archivo.
  • Vaciar Descartes: Elimina del proyecto todos los elementos de la lista de Descartes de una sola vez (no borra los archivos del disco).
  • Añadir Archivos al Proyecto: Igual que en Selección — permite añadir archivos de cualquier tipo soportado directamente a la lista.
  • Eliminar Permanentemente: ¡Cuidado! Elimina el archivo del disco de forma permanente, sin posibilidad de recuperación desde la papelera.

Sobre la tabla de exportación

  • Proporciona atajos para las acciones más comunes: asignar archivo comprimido, ignorar comprimido, mover a Descartes o quitar de la cola.
