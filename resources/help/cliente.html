Modo Cliente

El Modo Cliente es el espacio de trabajo para gestionar la revisión y selección de imágenes por parte de un cliente. Permite crear checkboxes sobre las imágenes, asignarles estados (Seleccionado, Descartado, Sin Marcar), añadir comentarios, y exportar un catálogo HTML autónomo que el cliente puede revisar y devolver con sus decisiones.

Flujo de Trabajo Típico

  1. Preparar el Proyecto: Desde el Modo Proyecto, marca las imágenes que quieres enviar al cliente.
  2. Entrar al Modo Cliente: Cambia al modo cliente desde el selector de modos.
  3. Configurar Checkboxes: Activa el panel de edición y añade checkboxes sobre cada imagen definiendo código, precio y posición.
  4. Añadir Comentarios: Escribe comentarios generales para cada imagen si es necesario.
  5. Exportar: Genera un HTML único (con miniaturas base64 incrustadas) o un catálogo web para enviar al cliente.
  6. Importar Respuesta: Cuando el cliente devuelva el JSON con sus decisiones, impórtalo para actualizar el proyecto.
  7. Sincronizar: Actualiza el proyecto con los cambios realizados por el cliente.
Nota: En el Modo Cliente, por defecto no se puede modificar la selección. Es el cliente quien decide. Si necesitas editar bajo tu responsabilidad, activa el botón "Editar selección" (se te pedirá confirmación).

Interfaz del Modo Cliente

1. Barras de Herramientas (Superior)

El modo cliente añade botones específicos a la barra de herramientas principal:

Nuevo Proyecto (Ctrl+N): Cierra el proyecto actual y crea uno nuevo vacío.
Abrir Proyecto (Ctrl+O): Carga un archivo de proyecto .prj existente.
Guardar Proyecto (Ctrl+S): Guarda los cambios en el archivo .prj actual.
Guardar Proyecto Como (Ctrl+Shift+S): Guarda en un nuevo archivo .prj.
Importar respuesta del cliente (JSON): Carga el archivo JSON devuelto por el cliente con sus decisiones (estados de checkboxes y comentarios).
Crear PDF: Genera un PDF con las imágenes marcadas como Seleccionadas (✓). Incluye cuadrícula 2×2 con código, precio, imagen y comentarios de cada una, más página de resumen con tabla de precios y total. Sirve como presupuesto o constancia.
Exportar catálogo web para el cliente: Genera un catálogo web con miniaturas y checkboxes para que el cliente los revise online.
Exportar HTML único para el cliente: Genera un archivo HTML autónomo con miniaturas base64, CSS y JS inline. El cliente puede abrirlo en cualquier navegador, revisar las imágenes, cambiar estados de checkboxes y exportar un JSON con sus decisiones.
Compartir con el cliente: Prepara y comparte el catálogo con el cliente.
Editar selección (Toggle con confirmación): Activa o desactiva la edición manual de los estados en los 4 grids de selección. Al activarlo, se muestra un diálogo de confirmación. Cuando está activo, puedes hacer clic en el estado de cualquier imagen para cambiar su tristate (Seleccionado → Descartado → Sin Marcar) y esto cascada a todos sus checkboxes internos.
Mover selección a descartes: Mueve las imágenes seleccionadas a la lista de descartes.
Panel edición checkboxes y comentarios (Toggle): Muestra u oculta el panel de edición de checkboxes. En este panel puedes añadir, posicionar y configurar checkboxes sobre la imagen actual, así como añadir comentarios generales.
Mostrar checkboxes en imágenes (Toggle): Activa o desactiva la visualización de los overlays de checkboxes sobre las imágenes en el visor.
Actualizar proyecto con cambios del cliente: Aplica al proyecto los cambios realizados durante la revisión (estados de checkboxes, comentarios, etc.).
Cerrar y sincronizar con el cliente: Finaliza la revisión y sincroniza los cambios con el proyecto.

2. Editor de Checkboxes

Al activar el Panel de edición de checkboxes, aparece un visor con la imagen actual y una barra de herramientas específica. También puedes usar atajos de teclado directamente sobre la imagen:

Añadir checkbox: Activa el modo de inserción. Haz clic en la imagen para colocar un nuevo checkbox en esa posición. Se abrirá un diálogo para configurar su código, precio y estado inicial. También puedes pulsar Ctrl+Click sobre la imagen para añadir un checkbox rápidamente sin usar el botón.
Añadir label: Activa el modo de inserción de comentarios. Haz clic en la imagen para colocar un comentario superpuesto. También puedes pulsar Ctrl+Shift+Click sobre la imagen para añadir un comentario rápidamente.
Finalizar edición de checkboxes: Desactiva el modo de edición y guarda los cambios realizados.

En el editor puedes arrastrar los checkboxes y comentarios para reposicionarlos, usar la rueda del ratón para hacer zoom, y el botón central para desplazar la imagen. El menú contextual (clic derecho) sobre un checkbox permite cambiar su estado, editar código, precio, borrarlo, o abrir su hilo de mensajes.

3. Los 4 Grids de Selección

El modo cliente muestra 4 grids que organizan las imágenes según su origen y estado:

  • Selecciones de Proyecto: Imágenes que el proyecto tiene marcadas como seleccionadas.
  • Descartes de Proyecto: Imágenes que el proyecto tiene marcadas como descartadas.
  • Selecciones de Cliente: Imágenes que el cliente ha seleccionado (según el JSON importado).
  • Descartes de Cliente: Imágenes que el cliente ha descartado.

Las tablas de cliente tienen 6 columnas: collapse (▶/▼), Est (tristate), C. IMG (código de imagen), C. CB (código de checkbox), PVP (precio), y Msg (icono de mensajes).

Ordenación: Haz clic en el encabezado de cualquier columna para ordenar ascendentemente (▼). Vuelve a hacer clic para orden descendente (▲), y una tercera vez para restaurar el orden natural. La ordenación por la columna Msg prioriza las imágenes según el estado de su conversación: primero las que tienen mensajes nuevos del cliente (rojo), luego las que esperan respuesta (azul), seguidas de las leídas (verde), y por último las que no tienen mensajes (gris).

Colapso de hijos: Cuando una imagen tiene checkboxes internos, la columna collapse muestra un indicador con el número de hijos. Haz clic en él para ciclar entre tres modos: NONE (todos los checkboxes visibles), SMART (solo los que tienen estado SELECTED o comentario), y FULL (solo la imagen padre).

Icono de mensaje (✉): La columna Msg muestra un sobre cuyo color indica el estado de la conversación de esa imagen o checkbox: ● Rojo = mensaje nuevo del cliente sin leer, ● Verde = mensaje leído, ● Azul = esperando respuesta del cliente, ● Gris = sin conversación. Haz doble clic en el icono para abrir el diálogo de mensajes.

Cada imagen en estos grids muestra un tristate (✓ Seleccionado / ✗ Descartado / ○ Sin Marcar) que refleja el estado de la imagen. Con el botón "Editar selección" activo, puedes hacer clic en el tristate para cambiar el estado, y este se propagará a todos los checkboxes internos de esa imagen.

4. Checkboxes (Tristate)

Los checkboxes en modo cliente tienen tres estados posibles que se ciclan al hacer clic:

  • ✓ SELECTED (Seleccionado): El cliente quiere esta imagen/checkbox.
  • ✗ DISCARDED (Descartado): El cliente descarta esta imagen/checkbox.
  • ○ UNDEFINED (Sin Marcar): Estado pendiente, el cliente aún no ha decidido.

Cada checkbox puede tener: código identificador, precio (PVP), comentario, y una posición (x, y) dentro de la imagen. El estado de la imagen se deriva del estado de sus checkboxes internos: si al menos uno está SELECTED, la imagen es SELECTED; si todos están DISCARDED, la imagen es DISCARDED; en cualquier otro caso, UNDEFINED.

5. Exportación HTML Único

La exportación a HTML único genera un archivo autónomo que contiene:

  • Todas las miniaturas de las imágenes incrustadas en base64.
  • CSS para la presentación (modo oscuro, galería responsiva).
  • JavaScript para la interactividad: tristates clickeables, modal con zoom/pan/pinch, overlays de checkboxes posicionados sobre la imagen, burbujas de comentarios.
  • Botón para copiar al portapapeles o descargar un JSON con las decisiones del cliente.

Al hacer clic en una imagen de la galería se abre un modal con zoom/pan/pinch. La rueda del ratón escala la imagen centrando el zoom en la posición del cursor. También puedes arrastrar la imagen para desplazarla, y en dispositivos táctiles funciona con gestos de pellizco.

El modal incluye un panel de chat lateral donde se muestran los comentarios de la imagen y de cada checkbox. El cliente puede escribir mensajes, y los mensajes nuevos aparecen con un indicador rojo. Las burbujas de comentario usan el mismo sistema de colores: rojo = mensaje nuevo, verde = leído, azul = contestado, gris = sin mensajes.

El cliente abre el HTML en su navegador, revisa las imágenes, cambia los estados y devuelve el JSON generado. Tú importas ese JSON con el botón "Importar respuesta del cliente".

Calidad adaptativa de miniaturas

Para mantener el HTML en un tamaño razonable, la calidad de las miniaturas se adapta: ≤20 imágenes → 800px de ancho / 85% calidad; ≤50 → 600px / 75%; >50 → 400px / 60%.

6. Sistema de Mensajes (Chat)

Cada imagen y cada checkbox interno puede tener un hilo de mensajes (CommentThread) que funciona como un chat. Para abrirlo, haz doble clic en el icono ✉ de la columna Msg en las tablas de cliente, o haz clic derecho sobre un checkbox en el editor y selecciona "Ver mensajes".

El diálogo de mensajes muestra el historial en formato de burbujas (como una conversación de chat). Puedes responder escribiendo en el área de texto inferior y pulsando "Enviar". Los mensajes escritos por ti (como fotógrafo/taller) se etiquetan como "nosotros", y los del cliente como "cliente".

Los mensajes tienen un sistema de 4 estados que se refleja en el color del icono ✉ de la tabla:

  • Rojo (Nuevo): El último mensaje es del cliente y no se ha abierto el diálogo. Indica que hay una respuesta pendiente de leer.
  • Verde (Leído): Has abierto el diálogo después de que el cliente escribiera, pero aún no has respondido.
  • Azul (Espera): El último mensaje es tuyo y el cliente aún no ha respondido. Estás esperando su contestación.
  • Gris (Sin mensajes): No hay ningún mensaje en el hilo. Es el estado por defecto de imagen/checkbox sin conversación.

Puedes borrar tus propios mensajes (los que no hayan sido compartidos con el cliente en iteraciones anteriores) pulsando el botón ✖ que aparece en la burbuja. Los mensajes del cliente o los ya compartidos no se pueden borrar.

El sistema de mensajes está integrado con la exportación HTML: los hilos de conversación se exportan al HTML del cliente, y cuando el cliente devuelve el JSON, sus respuestas se importan como nuevos mensajes del cliente en el hilo correspondiente.

Para la integración con el Modo Proyecto, consulta la sección Modo Proyecto.
