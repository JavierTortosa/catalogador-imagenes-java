Editor Avanzado

El Editor Avanzado es un editor de imágenes completo con soporte de capas, herramientas de selección, pintura, texto y transformación. Se activa desde el botón Editor Avanzado en la barra de herramientas de previsualización (Modo Render), sustituyendo al modo Collage. También es el editor que usa el Modo Editor (modo de trabajo dedicado con documentos .edoc, guardado y recuperación).

Documento, Guardado y Portapapeles

El editor se usa en dos contextos con documentos independientes:

  • Dentro del Modo Render: al activar el Editor Avanzado se trabaja sobre un lienzo en memoria (sin archivo). Al volver a este contexto se conserva la composición.
  • Modo Editor (documento dedicado): el trabajo se gestiona como un documento .edoc con nombre, cambios pendientes (* en el título), guardado temporal al cambiar de modo y recuperación automática si se cierra la aplicación sin guardar.

Al cambiar entre el Modo Render y el Modo Editor, cada contexto conserva su propio documento; para mover contenido entre ellos se usa el portapapeles. Desde cualquier contexto puedes copiar la imagen actual (clic derecho → Copiar imagen) y pegarla en el editor con Ctrl+V o el botón Pegar de la barra de documento, creando una capa nueva centrada en el lienzo.

Modo Home (Pantalla Inicial)

Al abrir el editor por primera vez se muestra el Modo Home, con dos pestañas excluyentes en la barra superior:

PestañaDescripción
Lienzo Crea un nuevo lienzo en blanco. Permite configurar ancho, alto, color de fondo y modo transparente antes de generarlo. Una vez creado, se activa el editor con un lienzo vacío.
Imagen Carga la imagen actualmente seleccionada en el visor principal como capa base del editor. Mantiene las dimensiones originales.

Si ninguna pestaña está seleccionada, se muestra un panel vacío (home_empty).

Barra de Herramientas Izquierda

Columna vertical con JToggleButton agrupados (solo uno activo a la vez). Cada herramienta cambia el comportamiento del ratón sobre el lienzo y muestra su propio panel de opciones en la barra inferior:

Edición: Herramienta por defecto. Selecciona, mueve y transforma capas. 1 clic sobre una capa la activa (si la auto-selección está activa), 1 clic en vacío deselecciona, y el arrastre mueve la capa activa. Si el checkbox "Tiradores" está activo se muestra el gizmo para redimensionar. Ver sección Edición.
Transformar: Muestra el gizmo de transformación sobre la capa activa (manejadores en esquinas y puntos medios). Permite mover, escalar y rotar la capa.
Selección por marco: Define una selección rectangular arrastrando sobre el lienzo. La selección se muestra con un desvanecido (feather) configurable.
Selección por capa: Crea una selección rectangular que se ajusta automáticamente a los bordes de la capa activa.
Varita mágica: Selecciona áreas de color similar con un clic. La tolerancia (0-255) se ajusta desde el panel de opciones.
Recortar: Arrastra para definir el área a conservar. Al soltar, una nueva capa se crea con el recorte. Opcionalmente mantiene la capa original.
Cuentagotas: Captura el color bajo el cursor y lo almacena como color frontal (foreground). El color capturado se muestra en el panel de opciones.
Bote de pintura: Rellena el área de color similar con el color frontal, con tolerancia configurable.
Degradado: Arrastra para definir la dirección de un degradado lineal entre dos colores (inicio y fin). Se crea una nueva capa con el degradado.
Texto: Crea y edita capas de texto (TextLayer). Arrastra para definir el rectángulo, o haz clic para auto-ajuste. Escribe directamente sobre el canvas. Ver sección Herramienta Texto.
Formas: Crea formas básicas (rectángulo, elipse, triángulo, línea, flecha) como nuevas capas de imagen. Configura relleno, borde y grosor desde el panel de opciones.
Pantalla completa: Expande el editor ocupando toda la ventana, ocultando el resto de la interfaz. Pulsa el mismo botón (o F) para salir. Esc nunca sale de pantalla completa: solo cancela la herramienta activa.

Navegación del Lienzo (Zoom y Paneo)

El lienzo admite zoom y paneo para trabajar cómodamente a distintas escalas:

  • Zoom: la rueda del ratón sobre el lienzo amplía o reduce la vista, centrando el zoom en la posición del cursor.
  • Paneo con el botón central: arrastrar con el botón central del ratón mueve el lienzo desde cualquier punto del área de trabajo. Es la forma de panear cuando el lienzo cubre todo el panel.
  • Paneo con el botón izquierdo (el lienzo como capa de fondo): el área oscura que rodea al lienzo actúa como el fondo de la composición. Si pulsas y arrastras con el botón izquierdo sobre esa zona oscura (fuera del lienzo) y no hay ninguna capa bajo el cursor, se mueve el lienzo y además se deseleccionan todas las capas. Una capa puede sobresalir del lienzo: si el clic (dentro o fuera del lienzo) cae sobre una capa, se selecciona y se arrastra como es normal.

Durante el paneo el cursor cambia al modo mover. Las herramientas solo actúan dentro del lienzo; la zona oscura paneea (salvo cuando hay una capa bajo el cursor, que se selecciona).

Controles de Color

En la parte inferior de la barra izquierda, justo encima del botón de pantalla completa, se encuentran los controles de color estilo Photoshop:

  • Color frontal: Es el color de primer plano. Se usa como color de pintura en el bote de pintura, como relleno de las formas, como color del texto y como color inicial del degradado.
  • Color de fondo: Es el color de segundo plano. Se usa como color final del degradado.
  • Intercambiar colores (): Intercambia el color frontal y el de fondo.
  • Restablecer colores (): Vuelve a los valores por defecto (frontal blanco, fondo negro).

Haz clic en el cuadrado pequeño (frontal) para elegir su color, y clic derecho en él para elegir el color de fondo (o clic en el cuadrado grande de detrás). El color capturado con el cuentagotas se asigna automáticamente al color frontal.

Historial de Pasos (Undo / Redo)

El editor mantiene un historial de hasta 50 pasos por documento. Cada paso guarda una copia completa del lienzo (tamaño, color de fondo, transparencia) y de todas las capas (imagen clonada en profundidad), de modo que deshacer restaura el estado exacto, incluidos los cambios de píxeles como el bote de pintura o el degradado.

  • Deshacer (Ctrl+Z) — deshace el último paso.
  • Rehacer (Ctrl+Y o Ctrl+Shift+Z) — rehace el paso anulado.
  • Historial — el botón central abre un menú con la lista de pasos; el paso actual se marca con ▶ y negrita. Pulsa cualquier paso para saltar a él (deshaciendo o rehaciendo automáticamente los necesarios).

Los tres botones viven en la fila superior de la Barra de Opciones Superior, a la izquierda de los checkboxes y de los combos de alineación. Se habilitan/deshabilitan según haya pasos que deshacer o rehacer.

¿Qué genera un paso? Los gestos de arrastre de herramienta se agrupan en un único paso (p. ej. mover, transformar o pintar de una sola vez). Las operaciones discretas (alinear, distribuir, espaciar, auto layout, propiedades de texto/forma, pegar imagen, nuevo/redimensionar lienzo, opacidad) se registran con su propio nombre. El historial se reinicia al crear, abrir o cargar un documento nuevo.

Herramienta Texto

La herramienta de texto crea capas de texto editables (TextLayer), que almacenan el contenido textual, la fuente, el color y los estilos como propiedades, en lugar de rasterizar el texto a una imagen. Soporta formato por carácter (rich text): distintos fragmentos del mismo texto pueden tener fuente, tamaño, negrita, cursiva, color, subrayado y tachado diferentes.

Creación y Edición

  • Arrastrar sobre el lienzo vacío → define el rectángulo de texto y aparece un JTextPane superpuesto para escribir directamente sobre el canvas. La capa conserva las dimensiones del arrastre y permite múltiples líneas con formato rico.
  • Single click sobre el lienzo vacío → modo auto-ajuste. Las dimensiones de la capa se calculan automáticamente según el contenido del texto. También usa JTextPane, con el mismo soporte de formato rico.
  • Enter o Ctrl+Enter → confirma el texto y crea la TextLayer con el nombre = primeros 30 caracteres del contenido.
  • Un clic sobre una TextLayer existente → re-edita el texto inline directamente (tipo Photoshop), restaurando el formato rico previo (TextRun) en el JTextPane.
  • Focus lost → también confirma automáticamente (excepto si el foco va a un control de la barra de opciones).
  • Cambiar de herramienta durante la edición inline → confirma el texto automáticamente (la capa se crea o actualiza antes de desactivar la herramienta).

Formato por Carácter

El texto se almacena internamente como una lista de TextRun, donde cada TextRun contiene: fuente, color, subrayado, tachado y el texto del fragmento. Esto permite que cada carácter o grupo de caracteres tenga su propio formato.

  • Seleccionar parte del texto con el ratón y cambiar cualquier propiedad (fuente, tamaño, negrita, color, subrayado, etc.) → el cambio se aplica solo a la selección.
  • Si no hay selección, los cambios de estilo se aplican como atributos de entrada por defecto para el texto que se escriba a continuación.
  • Al confirmar (Enter/focus lost), los runs se extraen del StyledDocument del JTextPane mediante extractRuns() y se almacenan en la capa.
  • Al re-editar (doble clic), los runs se restauran en el JTextPane mediante restoreRuns().
  • El pintado (paintRuns()) recorre los runs y dibuja cada fragmento con su fuente, color, subrayado y tachado, con soporte de múltiples líneas mediante \n.

Alineación en Modo Auto-Ajuste

En el modo auto-ajuste (single click), los botones de alineado usan el ancho de la primera línea como referencia:

  • Izquierda: el texto crece hacia la derecha desde el punto de clic.
  • Centro: la primera línea se centra en el punto de clic; las líneas siguientes se alinean respecto a ese centro.
  • Derecha: la primera línea termina en el punto de clic; las líneas siguientes se alinean a ese borde derecho.

Sincronización Barra ↔ Selección

Al mover el cursor o seleccionar texto en el editor inline, la barra de opciones se actualiza automáticamente para reflejar el formato del texto en la posición del cursor:

  • Si todo el texto seleccionado tiene atributos uniformes, los controles de la barra (fuente, tamaño, negrita, cursiva, subrayado, tachado) se actualizan para mostrar esos valores.
  • Si el texto seleccionado tiene atributos mixtos (ej. parte en negrita y parte no), los controles se dejan en blanco/indeterminado.
  • La alineación del párrafo se actualiza según el párrafo donde esté el cursor.
  • Esto permite saber en todo momento qué formato tiene el texto, especialmente útil al editar capas con formato rico preexistente.

Panel Derecho de Texto (sincronizado)

El panel derecho del editor (Herramientas → sección Texto) ofrece controles duplicados de formato de texto en dos pestañas:

  • Alineamiento: botones de alineación (izquierda, centro, derecha, justificado), flujo (línea/columna) y orientación (horizontal/vertical).
  • Fuentes: selector de familia tipográfica, tamaño (8–72) y estilos (negrita, cursiva, subrayado, tachado).

Estos controles están completamente sincronizados con la barra superior (Parte B) y con la herramienta Texto:

  • Al cambiar cualquier propiedad desde el panel derecho, se aplica en tiempo real al texto seleccionado y se actualiza la barra superior.
  • Al cambiar desde la barra superior, el panel derecho se actualiza al instante.
  • Al mover el cursor por un texto con formato rico, ambos paneles reflejan el formato de la posición actual.

Internamente, los controles del panel derecho reutilizan la lógica de EditorComponentBar.applyTextProperty(), de modo que los dos paneles se comportan como si fueran el mismo conjunto de controles.

Herramienta Edición (atajos)

La herramienta Edición es la herramienta universal de selección y manipulación. Además de la navegación básica, ofrece los siguientes comportamientos:

  • 1 clic sobre una capa → la activa (si la auto-selección está activa). Un clic en vacío deselecciona.
  • Arrastre → mueve la capa activa. El cursor cambia a modo mover sobre su área.
  • Alt+arrastre → duplica la capa activa y mueve la copia en el mismo gesto.
  • Ctrl+clic sobre una capa → la activa temporalmente (sin cambiar la selección permanente); al soltar, se restaura la capa activa previa.
  • Flechas del teclado → mueven la capa activa 1 px (Shift = 10 px).
  • Doble clic sobre una TextLayer o una capa de forma → edita su contenido (atajo). Abre la edición inline de texto o el panel de formas, según el tipo de capa.
  • Tiradores (gizmo): si el checkbox "Tiradores" está activo, se dibuja el TransformGizmo alrededor de la capa activa, permitiendo redimensionarla arrastrando sus manejadores y rotarla arrastrando el asa circular del borde superior (Shift = múltiplos de 15°).

Sincronización Bidireccional

  • Al hacer clic en una TextLayer, el panel de opciones (barra superior) y el panel derecho se actualizan con sus propiedades (fuente, tamaño, color, alineación, vertical).
  • Al cambiar una propiedad en cualquiera de los dos paneles, se aplica inmediatamente a la capa seleccionada y se refleja en el otro panel.
  • La capa creada se añade automáticamente al modelo y aparece en el panel de capas gracias al sistema de notificación (LayerModel.setChangeListener()).

Panel de Disposición

En el panel derecho, la sección Disposición agrupa todas las operaciones de colocación de capas en un acordeón exclusivo: las secciones se apilan una encima de la otra y, al expandir una (clic en su cabecera), las demás se cierran automáticamente. Esto mantiene el panel compacto; solo la sección que necesitas está abierta. Incluye:

  • Alinear: Alinea las capas seleccionadas respecto a la referencia elegida (ver Opciones). Con varias capas seleccionadas se alinean como si formaran una única capa virtual cuyo contorno es la unión de todas ellas (estilo Photoshop: si una capa va de (100,100) a otra que termina en (200,200), centrar coloca ambas en el punto 150).
  • Distribuir: Reparte las capas a intervalos iguales entre los valores extremos de la propia magnitud (bordes o centros), dejando fijas la primera y la última. La operación es idempotente (repetirla no dispersa las capas). Los botones se deshabilitan con menos de 3 capas efectivas.
  • Espacio: Iguala el hueco entre capas consecutivas sin mover la primera ni la última (estilo Photoshop "Distribute Spacing").
  • Auto Layout: 13 herramientas de composición automática que actúan solo sobre las capas seleccionadas (ver abajo). Las capas no seleccionadas se sacan del lienzo o se ignoran según la configuración.
  • Opciones: Configura la referencia de alineación de las herramientas de disposición (ver abajo). Los parámetros del sistema Auto Layout y de Smart Guides se configuran desde Configuración Avanzada → Editor.

Opciones — Referencia de Alineación

La alineación puede tomar como referencia uno de estos tres modos:

  • Lienzo: Alinea respecto a los bordes y al centro del lienzo completo.
  • Selección: Alinea respecto a la unión de las capas seleccionadas (la "capa virtual"). Es el modo por defecto y el comportamiento tipo Photoshop.
  • Capa maestra: Alinea las demás capas respecto a una capa designada. Pulsa "Usar capa activa como maestra" para fijar la capa actualmente activa como referencia, y "Quitar" para deshacerla. Si la capa maestra no existe o no es válida, se usa la selección.

El modo elegido también se aplica a los combos Alinear de la barra superior del editor, y se conserva mientras dure la sesión (no se guarda entre ejecuciones).

Sistema Auto Layout

El sistema Auto Layout sustituye al antiguo "Auto distribuir". Todas las herramientas actúan únicamente sobre las capas seleccionadas (visibles y no bloqueadas). Si no hay selección, no hacen nada. El panel se organiza en tres filas:

  • Fila 1: Grid Uniforme, Grid Conservando Tamaño | Layout Hero, Espiral, Mosaico.
  • Fila 2: Compactar, Compactar por Filas, Compactar por Columnas, Ajustar al Canvas.
  • Fila 3: Centrar Composición Horizontal/Vertical | Igualar Altura, Igualar Anchura.

Herramientas:

  • Grid Uniforme: cuadrícula de celdas iguales; cada capa se escala (con proporción) para encajar en su celda.
  • Grid Conservando Tamaño: cuadrícula que respeta el tamaño natural de las capas; el lienzo solo crece hacia la derecha y hacia abajo, sin desplazar el origen.
  • Compactar: empaqueta las capas sin solaparse minimizando los espacios vacíos, según el modo de empaquetado elegido (Estantes, Skyline o Guillotina).
  • Compactar por Filas / Columnas: distribuye las capas en filas o columnas con reparto equilibrado (12 capas dan 4/4/4, nunca 10/2).
  • Layout Hero: la capa activa (si está seleccionada; si no, la de mayor área) ocupa la superficie principal y el resto se distribuye a su lado.
  • Espiral: coloca las capas a lo largo de una espiral de Arquímedes desde el centro del lienzo.
  • Mosaico: cuadrícula con celdas de tamaño variable; ninguna capa modifica su tamaño más allá de la Variación mosaico configurada.
  • Ajustar al Canvas: escala la composición (uniforme) para que encaje en el lienzo con el margen de ajuste, sin modificar las posiciones relativas.
  • Centrar Composición: traslada la composición al centro horizontal o vertical del lienzo, sin redimensionar.
  • Igualar Altura / Anchura: ajusta el tamaño de las capas seleccionadas al de la capa activa (o la primera seleccionada), manteniendo la proporción y sin modificar la rotación ni la posición.

Reglas generales: ninguna operación modifica la rotación, la opacidad, el orden Z, el nombre ni la selección. Cada operación es una única entrada de deshacer/rehacer, es determinista y mantiene la proporción salvo que la herramienta indique lo contrario. Nunca se generan coordenadas negativas salvo cuando se sacan capas fuera del lienzo.

Parámetros configurables: se gestionan en Configuración Avanzada → Editor → Auto Layout:

  • No seleccionadas: fuera (las capas visibles no seleccionadas se desplazan fuera del lienzo) o ignorar (se dejan como están).
  • Espaciado: separación en píxeles entre celdas o capas.
  • Margen: margen general de las composiciones.
  • Margen ajustar: margen usado por Ajustar al Canvas.
  • Escala hero: proporción de la superficie que ocupa la capa principal.
  • Var. mosaico: variación máxima de tamaño permitida en el mosaico.
  • Empaquetado: algoritmo de Compactar (Estantes, Skyline, Guillotina).

Smart Guides

Las Smart Guides asisten el arrastre de capas con la herramienta de edición (Move Tool), estilo Photoshop: al mover una o varias capas, los bordes y centros se ajustan a los bordes y centros de las demás capas visibles y del lienzo.

  • Ajuste: cuando un borde o centro del rectángulo en movimiento queda a menos de la distancia de ajuste (6 px por defecto) de un candidato, la capa se alinea a ese candidato y se dibuja una guía de color a línea completa del lienzo.
  • Histéresis (pegajoso): una vez producido el ajuste, la guía se mantiene mientras el cursor no se aleje más de la distancia de retención (3 px), evitando que las guías parpadeen al mover el ratón.
  • Anulación: mantener Ctrl durante el arrastre desactiva temporalmente el ajuste y las guías.

Los parámetros (activación, ajuste a lienzo/capas, distancias, color y grosor) se configuran en Configuración Avanzada → Editor → Smart Guides.

Gizmo de Transformación

El TransformGizmo es un conjunto de tiradores visuales que se dibujan alrededor del rectángulo de una capa. Está disponible en la herramienta Transformar (para cualquier capa) y en la herramienta Edición cuando el checkbox "Tiradores" está activo.

Sus componentes son:

  • Marco: Línea delgada azul alrededor de los bounds de la capa.
  • 8 tiradores: Cuadrados en las esquinas (NW, NE, SW, SE) y puntos medios (N, S, E, W). Arrástralos para redimensionar. Al redimensionar desde una esquina, la esquina opuesta queda fija (la imagen crece/encoge hacia el ratón sin desplazarse); si "Mantener proporción" está activo, las esquinas mantienen la relación ancho/alto y los tiradores laterales redimensionan libremente.
  • Asa de rotación: Círculo sobre el borde superior. Arrástralo para rotar la capa de forma no destructiva (guardando el ángulo, sin rasterizar). Mantén Shift mientras arrastras para ajustar a múltiplos de 15°.
  • Cursor contextual: Cambia según el tirador activo.

El gizmo respeta las restricciones de tamaño mínimo (4 px) y proporción si está activo. Cuando la capa está rotada, el marco y los tiradores se dibujan también rotados.

Rotación No Destructiva

La rotación de capas es no destructiva: el editor guarda el ángulo de la capa como propiedad y lo aplica al pintar, de modo que la imagen o el texto originales no se modifican (estilo Photoshop). Consecuencias prácticas:

  • Imágenes: girar y volver a girar no acumula pérdida de calidad por redondeo.
  • Texto: un texto rotado sigue siendo completamente editable. Al hacer doble clic se abre la edición inline conservando su rotación, y los cambios de fuente, tamaño o contenido se aplican sin perder el ángulo.
  • Formas: también se rotan sin rasterizar.
  • Spinner de grados: en la barra de opciones aparece el campo Ángulo (de -360° a 360°), tanto en el panel de Edición para capas de imagen como en el panel de Texto para capas de texto. Escribir un valor o usar las flechas rota la capa al instante.

Panel de Capas

La pestaña "Capas" en el panel derecho muestra todas las capas como tarjetas visuales apiladas verticalmente (LayerCardPanel), con la capa superior arriba (estilo Photoshop). El panel dispone de una barra de scroll vertical (estrecha, 8px) que aparece automáticamente cuando las tarjetas no caben. Cada tarjeta incluye, de izquierda a derecha:

  • Ojo de visibilidad: Toggle que muestra/oculta la capa en el lienzo.
  • Candado de bloqueo: Toggle que impide modificar la capa. Las capas bloqueadas no se pueden mover, duplicar ni combinar, pero siguen siendo visibles. Este toggle se coloca antes del nombre para que nunca quede tapado por el scroll.
  • Miniatura: 40×40 generada por layer.renderThumbnail(40). En TextLayer muestra el texto truncado con la fuente escalada.
  • Nombre editable: Campo de texto para renombrar la capa. En TextLayer se asigna automáticamente con el contenido del texto. Es el elemento flexible de la tarjeta: se encoge antes que los toggles si el panel es estrecho.

Selección de Capas

  • Clic en una tarjeta → la convierte en la única capa activa (resaltado azul claro).
  • Ctrl+clic → añade o quita la capa de la selección múltiple.
  • Mayúsculas+clic → selecciona un rango continuo desde la capa activa.
  • La capa activa de la multiselección se distingue visualmente (fondo más claro) de las demás capas seleccionadas.
  • El clic funciona en cualquier parte de la tarjeta: miniatura, nombre o toggles.

Reordenación por Arrastre

Puedes arrastrar una tarjeta con el ratón para reordenarla dentro de la pila. Durante el arrastre aparece una línea azul que indica la posición de destino; al soltar, la capa se mueve a esa posición. Pulsa Esc para cancelar el arrastre en curso. Las capas bloqueadas no se pueden arrastrar.

Refresco Automático

El modelo de capas (LayerModel) incorpora un sistema de notificación (Runnable changeListener) que se dispara en cada mutación (añadir, eliminar, duplicar, mover, cambiar selección). El panel de capas y el canvas se refrescan automáticamente sin necesidad de intervención manual.

Gestión de Capas

Desde la barra vertical EAST (visible en el editor avanzado):

Añade capa nueva: Crea una capa vacía (transparente) del tamaño del lienzo.
Combina Capas: Fusiona las capas seleccionadas en una única capa de imagen, cuyo área es la unión de los bounds de las capas fusionadas. Reglas:
  • Se fusionan solo las capas seleccionadas visibles y no bloqueadas (requiere al menos dos).
  • Las seleccionadas ocultas se descartan (como Photoshop).
  • Las bloqueadas no se fusionan ni se descartan: permanecen intactas en su posición.
  • El resultado se coloca donde estaba la selección más alta, adopta el nombre de la capa superior y queda con opacidad completa, visible y sin bloqueo.
Tras combinar, la selección se limpia y la nueva capa queda activa.
Duplicar Capa: Crea una copia de la capa activa (o de cada capa seleccionada) justo encima de la original, con el mismo contenido, tamaño y propiedades. Las capas bloqueadas no se duplican.
Borrar capa: Elimina la capa actualmente seleccionada. Atajo: Supr o Retroceso.
Traer al frente: Mueve la capa seleccionada a la posición más alta.
Subir un nivel: Desplaza la capa una posición hacia arriba.
Bajar un nivel: Desplaza la capa una posición hacia abajo.
Enviar al fondo: Mueve la capa a la posición más baja.

El slider de opacidad situado bajo las tarjetas modifica la opacidad de la capa activa (funciona con cualquier tipo de capa, incluyendo TextLayer).
