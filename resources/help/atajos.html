Atajos de Teclado

Usa estos atajos para trabajar de forma más rápida y eficiente.

Navegación General

  • Flechas / Rueda Ratón: Imagen Siguiente/Anterior
  • Inicio / Fin: Primera / Última Imagen
  • Av Pág / Re Pág: Saltar bloque de imágenes
  • Ctrl + Alt + Rueda: Saltar bloque de imágenes (alternativo)

Gestión de Proyectos y Archivos

  • Barra Espaciadora: Marcar / Desmarcar imagen para el proyecto
  • Ctrl + L: Localizar archivo actual en el explorador
  • Clic Derecho sobre Ruta: Copiar ruta o añadir como filtro rápido

Acciones de Proyecto

  • Ctrl + S: Guardar Proyecto Actual
  • Ctrl + Shift + S: Guardar Proyecto Como...
  • Ctrl + N: Nuevo Proyecto
  • Ctrl + O: Abrir Proyecto Existente...

Ventana y Vista Global

  • F5: Refrescar vista (lista de archivos o proyecto)
  • F11: Activar / Desactivar Modo Pantalla Completa
  • Alt: Activar Foco en la Barra de Menú
  • ESC: Cerrar Ventana de Previsualización (si está abierta)

Zoom y Paneo (Sobre la imagen)

  • Rueda Ratón: Zoom (con modo zoom manual activo)
  • Shift + Rueda Ratón: Paneo Horizontal rápido
  • Ctrl + Rueda Ratón: Paneo Vertical rápido
  • Clic y Arrastrar: Panear imagen

Atajos Numéricos para Modos de Zoom (Fila de números o Teclado Numérico):

  • 1 / Numpad1: Ajustar a Pantalla
  • 2 / Numpad2: Tamaño Original (100%)
  • 3 / Numpad3: Ajustar a Ancho
  • 4 / Numpad4: Ajustar a Alto
  • 5 / Numpad5: Rellenar Pantalla
  • 6: Mantener Zoom Actual (Fijo)
  • 7: Zoom Personalizado (%)
  • 8: Activar/Desactivar Zoom/Paneo Manual
  • 9: Activar/Desactivar Zoom al Cursor
  • 0: Resetear Zoom

Nota: Los atajos de teclado numérico (Numpad1–Numpad5) no se activan cuando estás editando una celda de tabla o un campo de texto, para evitar que se ejecute el zoom accidentalmente.

Selección Múltiple

  • Ctrl + Clic: Añadir/quitar imagen de la selección múltiple
  • Mayúsculas + Clic: Seleccionar un rango continuo de imágenes
  • Barra Espaciadora: Marcar/Desmarcar todas las imágenes seleccionadas para el proyecto
  • Clic Derecho: Menú contextual con opciones como "Asignar Etiqueta..." sobre la selección múltiple

La selección múltiple se sincroniza automáticamente entre la lista de archivos, la barra de miniaturas y la cuadrícula (Grid).

Lista de Archivos

  • Flecha Izquierda / Derecha: Seleccionar archivo anterior / siguiente
  • 0-9 (dígitos): Salto rápido al siguiente archivo que empiece por ese dígito

Atajos del Grid (Modo Proyecto)

  • Ctrl + T: Añadir / Editar Etiqueta
  • Ctrl + Supr: Borrar Etiqueta
  • Ctrl + Más (+): Aumentar Tamaño de Miniaturas
  • Ctrl + Menos (-): Reducir Tamaño de Miniaturas
  • Rueda Ratón (sobre el grid): Navegar por filas completas

Atajos en Diálogos

  • ESC: Cerrar diálogo / Cancelar (Previsualización, Selección de Etiquetas, IntelliSense)
  • Tab / Clic: Seleccionar etiqueta del panel de autocompletado
  • Punto (.): Seleccionar etiqueta y bajar un nivel jerárquico
  • Enter: Confirmar el texto del campo (no selecciona del panel)
  • ↑ ↓: Navegar por las sugerencias del panel
