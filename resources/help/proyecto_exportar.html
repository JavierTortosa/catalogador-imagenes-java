Guía del Panel de Exportación

El Panel de Exportación es la herramienta para recopilar y organizar las imágenes de tu "Selección Actual" junto con sus archivos comprimidos asociados (.zip, .rar, etc.) para copiarlos a una carpeta de destino o generar un catálogo PDF.

Cómo abrir el Panel de Exportación

Estando en el Modo Proyecto, puedes abrirlo de cualquiera de estas formas:

  • Menú Proyecto → Panel de Control de Asignaciones
  • Botón Panel de Control de Asignaciones en la barra de herramientas principal (junto a Guardar/Eliminar proyecto).
  • Botón en la barra inferior del grid de proyecto.

El panel se abre como una vista dividida: la tabla de exportación aparece a la izquierda y el grid de proyecto se reduce a la derecha. Para cerrarlo, pulsa el mismo botón de nuevo (es un botón de tipo toggle).

Anatomía del Panel

El panel se divide en tres áreas funcionales:

1. La Tabla de Exportación

Es el componente central. Cuando se abre el panel, se puebla con las imágenes de tu "Selección Actual" y la aplicación busca automáticamente sus archivos asociados.

Columna Descripción
✔ (Checkbox) Permite seleccionar o deseleccionar un ítem para incluirlo en la exportación. Puedes marcar/desmarcar todos haciendo clic en la cabecera de la columna.
Código Código de catálogo para el PDF (C001, C002...). Solo se usa al generar el catálogo PDF; no afecta a la copia de archivos.
Imagen Muestra el nombre del archivo de la imagen.
Estado La columna más importante. Muestra con iconos y colores si se ha encontrado el archivo comprimido. Consulta la sección de estados más abajo.
Archivos Asignados Lista los nombres de los archivos comprimidos que se copiarán. Si hay más de un archivo asignado, aparecerá un icono especial que te invita a abrir el Panel de Detalles.
Tamaño Peso total estimado de la imagen más todos los archivos comprimidos asociados. Se muestra en formato legible (KB, MB, GB).

Nota: Puedes hacer clic derecho sobre una fila de la tabla para acceder a un menú contextual con acciones rápidas.

Ordenamiento: Haz clic en el encabezado de cualquier columna (Código, Estado, Tamaño, etc.) para ordenar la tabla ascendentemente. Vuelve a hacer clic para orden descendente.

2. El Panel de Detalles

Ubicado debajo de la tabla, este panel muestra en detalle la lista de rutas completas de los archivos comprimidos asignados. Para mostrarlo, pulsa el botón en la barra de acciones.

¡Truco! Cuando seleccionas una fila en la tabla con múltiples archivos asignados, el botón para mostrar los detalles en la barra de acciones se resaltará con un marco para indicarte que es relevante.

Este panel tiene su propia barra de botones para gestionar los archivos de la lista:

Añadir: Permite asignar manualmente uno o más archivos comprimidos adicionales.
Quitar: Elimina un archivo asociado de la lista (no borra el archivo del disco).
Localizar: Abre el explorador de archivos en la ubicación del archivo asociado seleccionado.

3. La Barra de Acciones de Exportación

La barra de herramientas Acciones de Exportación se encuentra en el panel lateral derecho de la ventana principal (solo visible en Modo Proyecto). Contiene todos los controles para gestionar la cola de exportación:

Seleccionar Carpeta: Abre un diálogo para elegir la carpeta de destino (obligatorio para exportar). El campo de texto inferior mostrará la ruta seleccionada.
Mostrar/Ocultar Detalles: Alterna la visibilidad del panel de detalles inferior.
Asignar Archivo: Permite localizar manualmente el/los archivo(s) comprimido(s) si la aplicación no lo encontró.
Ignorar Comprimido: Marca un archivo como "listo" aunque no tenga archivo asociado. Se exportará solo la imagen.
Relocalizar Imagen: Si una imagen del proyecto fue movida, permite encontrarla en su nueva ruta.
Refrescar Estado: Vuelve a escanear el disco para actualizar el estado de todos los archivos.
Mover a Descartes: Quita la imagen de la cola de exportación y la mueve a "Descartes".
Iniciar Exportación: Comienza la copia. Solo se activa cuando hay una carpeta de destino y todos los ítems marcados están listos.
Exportar a PDF Te permite crear un catálogo visual profesional en formato PDF con las imágenes seleccionadas, ideal para presentar a clientes.

Entendiendo la Columna 'Estado'

El estado de cada ítem determina si puede ser exportado. Aquí tienes la guía de colores y significados:

Estado Significado y Acción Requerida
OK ¡Perfecto! La aplicación ha encontrado el archivo asociado. No se requiere acción.
MANUAL Has asignado manualmente un archivo. El ítem está listo.
ZIP IGNORE Has decidido exportar esta imagen sin archivo comprimido. El ítem está listo.
NO ZIP No se encontró archivo asociado. Debes asignarlo manualmente o ignorarlo.
IMG. PERDIDA ¡Error Crítico! El archivo de la imagen no se encuentra. Usa "Relocalizar Imagen".

Generación de Catálogo PDF

Datos por imagen

Cada imagen del catálogo puede incluir los siguientes campos editables. Se configuran desde la Tabla de Detalles PDF (botón Detalles PDF en la barra de acciones) o desde la Vista Previa antes de generar:

CampoDescripción
CódigoIdentificador único (C001, C002...). Se genera automáticamente si está vacío.
Piezas C/SNúmero de piezas con soporte. Se auto-puebla desde el análisis del archivo comprimido si no lo has modificado.
Piezas S/SNúmero de piezas sin soporte. Se auto-puebla desde el análisis si no lo has modificado.
PiezasNúmero total de piezas que componen el modelo. Se auto-puebla desde el análisis si no lo has modificado.
LycheeIndica si el archivo contiene formato Lychee (.lys). Checkbox editable manualmente.
ChituboxIndica si el archivo contiene formato Chitubox (.ctb). Checkbox editable manualmente.
Tamaño TotalTamaño total del contenido comprimido en MB. Se puede editar manualmente si el valor automático no es correcto.
LVLNivel de dificultad de pintado (ej. Fácil, Medio, Difícil).
PVPPrecio de venta al público de la figura.
NotasObservaciones adicionales sobre la imagen.

Importante: Los valores de Piezas C/S, Piezas S/S y Piezas se auto-pueblan desde el análisis del archivo comprimido (usando 7z) solo la primera vez. Si los modificas manualmente, el análisis posterior no los sobreescribirá. Todos los datos se guardan en el archivo .prj del proyecto.

Análisis de archivos comprimidos

Al pulsar Detalles PDF o Exportar a PDF, la aplicación analiza automáticamente los archivos comprimidos (.zip, .rar, .7z) para extraer:

  • Recuento de archivos .stl, .obj, .3mf (piezas totales, con soporte y sin soporte)
  • Detección de archivos .lys (Lychee) y .ctb (Chitubox)
  • Tamaño total del contenido comprimido

El análisis también revisa archivos anidados (por ejemplo, un .rar que contiene otros .rar o .zip dentro), explorándolos recursivamente para contar todas las piezas.

Durante el análisis, se muestra una barra de progreso que permite cancelar la operación si es necesario. Los resultados se almacenan en una caché local (SQLite) para evitar re-analizar el mismo archivo.

Flujo de trabajo

  1. Revisa la tabla de exportación y marca con el checkbox las imágenes que quieres incluir.
  2. Pulsa Detalles PDF para abrir la tabla de detalles, donde se hará el análisis automático de los archivos comprimidos.
  3. Rellena o ajusta los campos (Piezas C/S, Piezas S/S, Lychee, Chitubox, LVL, PVP, Notas, etc.) desde la Tabla de Detalles PDF.
  4. Pulsa Exportar a PDF.
  5. Se abre la Vista Previa donde puedes revisar todas las imágenes, modificar los campos sobre la marcha (incluyendo checkboxes Lychee/Chitubox y Tamaño), o quitar imágenes que no quieras.
  6. Confirma y elige dónde guardar el archivo .pdf.
¿Buscas exportar un catálogo interactivo para el cliente? El Panel de Exportación se centra en la copia de archivos y el catálogo PDF. Para generar un catálogo HTML autónomo que el cliente pueda revisar en su navegador, cambiar estados y devolver sus decisiones, usa el Modo Cliente → Exportar HTML Único. Consulta la guía del Modo Cliente para más detalles.

Estructura del PDF

  • Hasta 4 imágenes por página organizadas en una cuadrícula de 2×2.
  • Cada imagen se muestra dentro de un recuadro con su foto y los datos asociados (Código, Piezas, LVL, PVP, Notas).
  • Si el proyecto tiene una descripción rellena, se añade una última página con las notas del proyecto.
